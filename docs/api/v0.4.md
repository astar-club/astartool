# astartool v0.4

本文档为 astartool **0.4** 版本的函数手册。相对 v0.3 的主要变更见文末
[变更摘要](#changelog-v04)；新增/修改的模块会在对应小节标题后以
`[v0.4 新增]` / `[v0.4 变更]` 标注。其余模块与 v0.3 保持一致，本文一并列出以保持完整。

<a id="changelog-v04"></a>

## 变更摘要（v0.4）

- `astartool.project._decorators` 新增 `singleton`：按 `__init__` 签名归一化
  `args`/`kwargs` 作为缓存 key 的单例类装饰器（位置参数与关键字参数等价，
  支持 `dict`/`list` 等可哈希规整）。
- `astartool.project._profiler.do_cprofile` 改用 `wrapt` 嵌套工厂写法。
- `astartool.file.file_opt` 新增 `read_large_file` / `write_large_file`：按
  `chunk_size` 流式（分块）读写的生成器/可迭代接口，避免一次性载入全部数据。
- `astartool.file.file_opt.write_file` 新增 `mode` 参数，支持 `mode="bytes"`
  二进制写入（`bytes`/`bytearray`），文本模式互不兼容时会抛 `FileOptError`。
- `setup.py` 的 `long_description` 改为读取 `README.md` 并声明
  `long_description_content_type='text/markdown'`；短描述改为英文。
- 删除冗余的旧 `project2lines.py` 模块，其功能以 pathlib 版 `file_to_lines` /
  `walk` / `project_to_lines` 留在 `astartool.project._project`。

# astartool.project.\_decorators

## singleton `[v0.4 新增]`

```python
def singleton(cls) -> type
```

单例类装饰器。首次以某组构造参数实例化时创建对象并缓存；之后以**等价**的
构造参数再次实例化时直接返回已缓存的同一实例。

缓存 key 通过 `inspect.signature` 将位置参数与关键字参数绑定到 `__init__`
签名上，归一化为一份有序的 `(参数名, 值)` 序列。因此以下写法被视为同一实例：

```python
@singleton
class Point:
    def __init__(self, x=0, y=0):
        self.x, self.y = x, y

Point(1, y=2)
Point(1, 2)
Point(**{"x": 1, "y": 2})   # 三者是同一对象
```

参数值会被规整为可哈希形式（`dict` → 排序元组、`list`/`tuple`/`set` →
递归元组），因此以 `dict`/`list` 为参数的单例也能正确缓存且互不相同。

**参数**:

- `cls`: 被装饰的类。

**返回**: 包装后的类，调用时返回单例实例。

**示例**:

```python
from astartool.project._decorators import singleton

@singleton
class Config:
    def __init__(self, path):
        self.path = path

a = Config("/etc/a.conf")
b = Config("/etc/a.conf")   # 与 a 是同一对象
c = Config("/etc/b.conf")   # 不同参数 -> 另一个单例
assert a is b
assert a is not c
```

## do\_cprofile `[v0.4 变更]`

```python
def do_cprofile(filename)
```

cProfile 性能分析装饰器，执行后将统计结果 dump 到 `filename`（.pfl 文件，
可用 gprof2dot + Graphviz 可视化）。

**变更**：v0.4 起改用 `wrapt` 嵌套工厂实现（`@wrapt.decorator` 包裹内层
`wrapper(wrapped, instance, args, kwargs)`），执行体始终 `dump_stats(filename)`
（位于 `finally` 之外，正常返回后落盘）。

**参数**:

- `filename`: 性能分析结果输出路径。

# astartool.file.file\_opt

<a id="astartool.file.file_opt.read_large_file"></a>

## read\_large\_file `[v0.4 新增]`

```python
def read_large_file(file_path: str,
                    chunk_size: int = 8 * 1024 * 1024,
                    mode="str", encoding="utf-8")
```

流式读取大文件，按分块返回内容，避免一次性将全部数据载入内存。

与 `read_file` 不同，本函数不读取完整文件后再切片，而是按 `chunk_size`
分块（流式）读取。`mode="str"` 时按文本模式逐块读取并返回生成器（每次产出
`str`）；其他 mode 按二进制模式读取并返回生成器（每次产出 `bytes`）。

**参数**:

- `file_path`: 待读取的文件路径。
- `chunk_size`: 单次读取的字节数（文本模式下按字符读取同样大小）。
- `mode`: `"str"` 按文本读取，其他值（如 `"bytes"`）按二进制读取。
- `encoding`: 文本模式下的文件编码。

**返回**: 一个生成器，逐个产出分块内容（`str` 或 `bytes`）。

**异常**: `FileOptError("not_a_file")` / `FileOptError("read_error")`。

**示例**:

```python
from astartool.file.file_opt import read_large_file

for chunk in read_large_file("big.log", chunk_size=1024 * 1024):
    process(chunk)   # 逐块处理，内存不随文件增大
```

<a id="astartool.file.file_opt.write_large_file"></a>

## write\_large\_file `[v0.4 新增]`

```python
def write_large_file(file_path: str, data,
                     chunk_size: int = 8 * 1024 * 1024,
                     mode="str", encoding="utf-8") -> int
```

流式写入大文件，按分块写入数据，避免一次性持有全部内容。

`data` 可为单一的 `str`/`bytes`，也可为产生 `str`/`bytes` 的可迭代对象
（生成器/列表等）。写入前会确保父目录存在。返回写入的字节数（文本模式按
`encoding` 编码后计算，二进制模式直接累加）。

**参数**:

- `file_path`: 目标文件路径。
- `data`: 待写入的数据（单一 `str`/`bytes`，或产生 `str`/`bytes` 的可迭代对象）。
- `chunk_size`: 单次写入的字节数（仅当 `data` 为单一 `str`/`bytes` 时用于分块）。
- `mode`: `"str"` 按文本写入，其他值按二进制写入。
- `encoding`: 文本模式下的文件编码。

**返回**: 实际写入的字节数。

**异常**: `FileOptError("mkdir_error")` / `FileOptError("write_error")`。

**示例**:

```python
from astartool.file.file_opt import write_large_file

def chunks():
    for i in range(10):
        yield f"line {i}\n"

write_large_file("out.txt", chunks(), chunk_size=1024)
```

## write\_file `[v0.4 变更]`

```python
def write_file(file_path: str, content: str,
               mode="str", encoding="utf-8") -> int
```

以 `content` 全量覆盖写入文件（父目录自动创建）。

**变更**：新增 `mode` 与 `encoding` 参数。`mode="str"`（默认）按文本写入，
接受 `str`，返回字符数；`mode="bytes"`（或其他非 `"str"` 值）按二进制写入，
接受 `bytes`/`bytearray`，返回字节数。类型不匹配时抛
`FileOptError("type_error")`。

**参数**:

- `file_path`: 写入路径。
- `content`: 完整内容（文本模式为 `str`，二进制模式为 `bytes`/`bytearray`）。
- `mode`: `"str"` 按文本写入，其他值按二进制写入。
- `encoding`: 文本模式下的文件编码。

**返回**: 文本模式返回字符数，二进制模式返回字节数。

**异常**: `FileOptError("type_error")`。
