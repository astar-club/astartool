# astartool v0.3

本文档为 astartool **0.3** 版本的函数手册。相对 v0.2 的主要变更见文末
[变更摘要](#changelog-v03)；新增/修改的模块会在对应小节标题后以
`[v0.3 新增]` / `[v0.3 变更]` 标注。其余模块与 v0.2 保持一致，本文一并列出以保持完整。

<a id="changelog-v03"></a>

## 变更摘要（v0.3）

- `astartool.file.file_opt` 新增 `edit_file`：基于精确匹配的批量替换（多组 `old/new`）或全量覆盖，配套异常 `FileOptError`。
- `astartool.file.downloadhelper` 新增 `download_large_file`：URL 流式下载，支持断点续传与进度回调。
- `astartool.number._number.is_prime` 改用 `secrets.randbelow`，并使用 `number < 2` 早返回（密码学安全随机）。
- `astartool.project._project_opt` 新增 `run_shell` / `install_packages`：与 MCP/注册表解耦的本地 shell 与依赖安装助手。
- `requirements.txt` 移除未使用的 `scipy` 依赖。
- `astartool.setuptool._tool.setup` 兼容标准 `version=` 元组键（不再强制要求 `api=`）。
- 新增异常 `astartool.error.file_opt_error.FileOptError`。

<a id="astartool.error.file_opt_error.FileOptError"></a>

## FileOptError

```python
class FileOptError(Exception)
```

基础文件操作异常。`code` 为机器可读的短原因码（沿用旧 McpResult 失败码，如
`not_readable` / `path_outside_workspace` / `edit_no_match` / `length_mismatch` /
`missing_argument` / `not_a_file` / `unsupported_archive` / `archive_error` /
`resume_range_invalid` / `http_error` / `url_error` / `io_error`），异常消息携带人类可读细节。

```python
err = FileOptError("edit_no_match", "no match for the given 'old' text")
err.code      # "edit_no_match"
str(err)      # 人类可读消息
```

由 `astartool.file.file_opt` 与 `astartool.file.downloadhelper` 抛出。需显式导入：

```python
from astartool.error.file_opt_error import FileOptError
```

<a id="astartool.file.file_opt.edit_file"></a>

#### edit\_file `[v0.3 新增]`

```python
def edit_file(file_path: Union[str, Path],
              old: Optional[List[str]] = None,
              new: Optional[List[str]] = None,
              content: str = "") -> dict
```

通过精确匹配替换或全量覆盖编辑工作区文件。两种互斥模式：

* ``{old, new}``：将每个 ``old[i]`` 的**首次精确出现**替换为 ``new[i]``。
  ``old`` 与 ``new`` 必须为等长列表；若某 ``old`` 无匹配，抛出 `FileOptError`
  （code ``edit_no_match``），调用方可重读后重试。
* ``{content}``：全量覆盖文件（父目录自动创建）。

:param file_path: 待编辑文件路径。
:param old: 待定位并替换的精确文本列表；``None``/空则禁用替换模式。
:param new: 与 ``old`` 平行的替换文本列表。
:param content: 用于全量覆盖的完整文本（当 ``old`` 为空时使用）。
:return: ``{"path": str, "bytes": int, "mode": "replace"|"overwrite"}``。
:rtype: dict
:raises FileOptError: 文件不存在、长度不匹配、``old`` 无匹配或参数非法时抛出。

示例：

```python
from astartool.file.file_opt import edit_file

# 多组替换
edit_file("demo.py", old=["def foo():", "return 1"], new=["def bar():", "return 2"])

# 全量覆盖
edit_file("demo.py", content="# rewritten\n")
```

<a id="astartool.file.downloadhelper.download_large_file"></a>

#### download\_large\_file `[v0.3 新增]`

```python
def download_large_file(url: str, dest: str,
                        chunk_size: int = DEFAULT_CHUNK_SIZE,
                        timeout: int = 30, headers: dict = None,
                        resume: bool = False, progress_cb=None) -> dict
```

以流式方式将（可能很大的）URL 文件下载到本地磁盘。

响应体按固定大小分块读取，内存占用与文件大小无关。每个分块后可选地调用进度回调。
当 ``resume`` 为 ``True`` 且 ``dest`` 已存在部分下载时，会通过 ``Range`` 请求从本地
字节偏移继续（若服务端支持 HTTP 206）；否则从头重新下载。

:param url: 下载源 URL。
:param dest: 本地目标路径（父目录自动创建）。
:param chunk_size: 每个分块读写的字节数（默认 64 KiB）。
:param timeout: 请求套接字超时秒数。
:param headers: 额外请求头（如 ``{"Authorization": "..."}``）。
:param resume: 在可能时通过 HTTP ``Range`` 启用断点续传。
:param progress_cb: 可选回调 ``(downloaded, total)``；服务端未提供 ``Content-Length`` 时 ``total`` 为 ``None``。
:return: ``{"dest", "bytes", "resumed", "total"}``。
:rtype: dict
:raises FileOptError: 网络或 HTTP 错误、或不支持的断点续传时抛出。

示例：

```python
from astartool.file.downloadhelper import download_large_file

res = download_large_file(
    "https://example.com/big.iso", "big.iso",
    resume=True,
    progress_cb=lambda d, t: print(f"{d}/{t}"),
)
print(res["bytes"], res["resumed"])
```

<a id="astartool.project._project_opt.run_shell"></a>

#### run\_shell `[v0.3 新增]`

```python
def run_shell(command: str, workspace: str, cwd: str = "",
              safe_path_fn: Optional[Callable[[str], Optional[Path]]] = None,
              timeout: int = SHELL_TIMEOUT_SEC) -> dict
```

在工作区沙箱内运行 shell 命令并返回结果 dict。

安全模型：

* 白名单内的构建/测试/VCS 只读命令直接运行（非破坏性）；
* 其余命令经由系统 shell 执行，调用方须在派发前自行确认；
* 机器级/不可恢复命令（如 ``mkfs`` / ``dd`` / ``rm /*``）直接拒绝。

:param command: shell 命令字符串。
:param workspace: 命令允许触及的根目录（默认 cwd）。
:param cwd: 可选工作目录（相对 ``workspace`` 或绝对路径）。
:param safe_path_fn: 可选沙箱守卫 ``str -> Path | None``；为 ``None`` 时不校验路径（由调用方负责沙箱）。
:param timeout: 单命令超时秒数（默认 120）。
:return: 成功 ``{"ok": True, "data": {"exit", "stdout", "truncated"}}``；
    失败 ``{"ok": False, "error": {"code", "message"}}``。
:rtype: dict
