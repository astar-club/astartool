# astartool.project.\_decorators

<a id="astartool.project._decorators.deprecated_version"></a>

## deprecated\_version `[v0_4_2 变更]`

```python
def deprecated_version(deprecated_since, removed_in=None, current_version=None,
                      message=None, removed_message=None,
                      exception=VersionDeprecatedError)
```

惰性版本过期提示装饰器。在首次调用被装饰函数时，将当前版本号与过渡区间
`[deprecated_since, removed_in)` 对比：

- 当前版本 **低于** `deprecated_since`：未进入弃用期，正常执行，无提示；
- 当前版本 **处于** 区间内（`deprecated_since <= current < removed_in`）：
  发出弃用 `DeprecationWarning` 提示切换方法，但函数**仍可使用**；
- 当前版本 **达到/高于** `removed_in`（`current >= removed_in`）：发出弃用
  提示，并抛出异常，函数**不再可用**。

**v0_4_2 起同时支持同步函数与 `async def` 异步函数**：装饰异步函数时返回的仍是
协程函数（`inspect.iscoroutinefunction` 为真），版本校验在协程被 `await` 执行时
进行，异常亦在 `await` 时抛出。

**参数**:

- `deprecated_since`: 弃用起始版本（过渡区间下界），可为元组或字符串。
- `removed_in`: 移除版本（过渡区间上界，开区间）；为 `None` 时取
  `deprecated_since`，即该版本起既提示又不可用。
- `current_version`: 当前版本；为 `None` 时取 `astartool.version`。
- `message`: 区间内（弃用但仍可用）的自定义提示，支持 `{current}` /
  `{transition}` / `{func}` 占位符。
- `removed_message`: 已达移除版本（不可用）的自定义提示，占位符同上。
- `exception`: 版本达到移除界限时抛出的异常类（默认
  `VersionDeprecatedError`）。

**示例**:

```python
from astartool.project._decorators import deprecated_version

@deprecated_version((0, 3, 0), (0, 4, 0),
                    message="old_api 已弃用，请改用 new_api")
def old_api():
    return "legacy"

# 异步函数同样支持（await 时才校验版本）
@deprecated_version((0, 3, 0), (0, 4, 0))
async def old_api_async():
    return "legacy"
```

## require\_optional\_import `[v0_4_2 变更]`

```python
def require_optional_import(module_name, error_message=None, exception=ImportError)
```

惰性加载装饰器：在被装饰函数首次调用时尝试导入 `module_name`。导入失败
（`ModuleNotFoundError` / `ImportError`）时抛出定制异常，异常信息可通过
`error_message` 自定义。导入探测结果按被装饰函数缓存，重复调用不会重复探测。

**v0_4_2 起同时支持同步函数与 `async def` 异步函数**：装饰异步函数时返回的仍是
协程函数（`inspect.iscoroutinefunction` 为真），依赖探测在 `await` 执行时进行，
缺包异常亦在 `await` 时抛出。

**参数**:

- `module_name`: 需要惰性导入的包/模块名（如 `"numpy"`、`"openpyxl"`）。
- `error_message`: 自定义报错信息；可包含 `"{module}"` 占位符，运行时替换为
  `module_name`。
- `exception`: 导入失败时抛出的异常类（默认 `ImportError`）。

**示例**:

```python
from astartool.project._decorators import require_optional_import

@require_optional_import("numpy", "请先安装 numpy: pip install numpy")
def heavy_compute():
    import numpy as np
    return np.array([1, 2, 3])

@require_optional_import("numpy")
async def heavy_compute_async():
    import numpy as np
    return np.array([1, 2, 3])
```

## project\_to\_lines `[v0_4_2 变更]`

```python
def project_to_lines(src_project,
                     to_file='out.txt',
                     start_file='\n',
                     end_file='\n',
                     allow_extension=list_allow_extension,
                     ignore=list_ignore,
                     compress_blank=True,
                     max_blank=1)
```

项目打印为文件（申请软著用，pathlib 版本）。递归遍历 `src_project`，将允许
扩展名的文件内容拼接为单个文本文件，每个文件前写入一行文件路径作为分隔。

**v0_4_2 变更**:

- 修复 CRLF 源码换行翻倍导致导出空行过多：`file_to_lines` 此前以默认文本
  模式写入目标文件，Windows 上内容中的 `\n` 被转换成 `\r\n`，使 CRLF 换行
  的源码变成 `\r\r\n`，读回时被拆成两行——每个源码行后都多出一个空行
  （astartool 自身导出时 txt 行数由 5329 涨到 9121、PDF 由 107 页涨到
  183 页，过半页面被空行占据）。现写入时禁用换行转换（`newline=''`），并在
  解码后将源码换行统一为 `\n`，行数口径与 `splitlines()` 统计一致。
- 新增 `compress_blank` / `max_blank` 参数：导出后自动**压缩连续空行**（默认
  保留至多 1 行）并去掉首尾空行。源码拼接时每个文件头尾都会附加空行
  （`start_file` / `end_file`），叠加源码自身的空行后文件中间会出现大量连续
  空行，软著排版时每页空白过多，故默认开启压缩；传
  `compress_blank=False` 可保留旧行为。
- 返回值由 `None` 改为统计字典
  `{"file_count": 文件数, "source_lines": 源码总行数}`；源码总行数不含文件头尾
  附加内容，但含源码自身的空行与注释。目标文件已存在时会交互询问是否删除
  （`alert_dialog`），用户拒绝时返回空统计并放弃导出。
- `file_to_lines` 返回写入的源码行数（解码失败跳过时返回 `0`）；`walk` 返回
  同样的统计字典。

**参数**:

- `src_project`: 源项目根目录（str 或 pathlib.Path）。
- `to_file`: 转化到的文件名（str 或 pathlib.Path）。
- `start_file`: 文件开始附加内容。
- `end_file`: 文件结束附加内容。
- `allow_extension`: 需要转换的文件后缀集合。
- `ignore`: 忽略转换的文件和文件夹。
- `compress_blank`: 是否压缩导出结果中的连续空行，默认 `True`。
- `max_blank`: 连续空行最多保留的行数，默认 1；仅 `compress_blank` 为真时生效。

## project\_to\_pdf `[v0_4_2 新增]`

```python
def project_to_pdf(src_project,
                   to_dir='softcopyright',
                   software_name='',
                   version=(0, 1, 0, 'final', 0),
                   allow_extension=list_allow_extension,
                   ignore=list_ignore,
                   start_file='\n',
                   end_file='\n',
                   lines_per_page=50,
                   keep_pages=30,
                   max_pages=60,
                   compress_blank=True,
                   max_blank=1,
                   encoding='utf-8')
```

导出软著用源代码 PDF：输入工程根目录，输出完整源码 PDF，并按软著要求输出
前后各 `keep_pages` 页的提交版 PDF。

流程：

1. 若 `<to_dir>/source_code.txt` 已存在，交互询问是否删除，用户拒绝则放弃
   本次导出（返回的 `pdf` 为 `None`）；
2. 调用 `project_to_lines` 把工程源码拼接为 `<to_dir>/source_code.txt`
   （自动压缩连续空行）；
3. 排版为完整源码 PDF `<to_dir>/source_code.pdf`（A4、每页固定行数、页眉含
   软件名+版本+源码总行数、页脚页码）；目标 PDF 已存在时同样交互询问是否
   删除，拒绝则放弃导出；
4. 总页数超过 `max_pages`（默认 60 页）时，只提交前 `keep_pages` 页 + 后
   `keep_pages` 页（默认各 30 页），另存为
   `<to_dir>/source_code_head<N>_tail<N>.pdf`；未超过时无需拆分，
   `pdf_part` 为 `None`（完整版即提交版）；提交版 PDF 已存在时同样交互询问，
   拒绝则仅输出完整版。

依赖 reportlab（可选依赖，未安装时抛出带安装提示的 `ImportError`，可通过
`pip install reportlab` 或 `pip install astartool[optional]` 安装）。

**参数**:

- `src_project`: 源项目根目录（str 或 pathlib.Path）。
- `to_dir`: 输出目录（默认 `softcopyright`，str 或 pathlib.Path），不存在则
  自动创建。
- `software_name`: 软著登记的软件名称（页眉展示）。
- `version`: 软件版本号，元组（如 `(1, 0, 0, 'final', 0)`）或字符串。
- `allow_extension`: 需要转换的文件后缀集合。
- `ignore`: 忽略转换的文件和文件夹。
- `start_file` / `end_file`: 每个源码文件头部/尾部附加内容。
- `lines_per_page`: PDF 每页行数，默认 50。
- `keep_pages`: 软著提交版前后各自保留的页数，默认 30。
- `max_pages`: 超过该页数才拆分软著提交版，默认 60。
- `compress_blank` / `max_blank`: 透传给 `project_to_lines` 的空行压缩参数。
- `encoding`: 文本文件编码。

**返回值**: 统计信息字典，键含义：

- `txt`: 拼接出的源码文本路径。
- `pdf`: 完整源码 PDF 路径；源码文本或完整版 PDF 已存在且用户拒绝删除、
  放弃本次导出时为 `None`。
- `pdf_part`: 软著提交版（前后各 `keep_pages` 页）PDF 路径；未超过
  `max_pages`、放弃导出、或用户拒绝删除已存在的提交版 PDF 时为 `None`。
- `total_pages`: 完整源码 PDF 总页数（放弃导出时为 0）。
- `part_pages`: 软著提交版页数（未拆分时等于 `total_pages`，未生成时为 0）。
- `source_lines`: 源码总行数（含空行/注释，不含文件头尾附加内容）。
- `file_count`: 源码文件数。

**示例**:

```python
from astartool.project import project_to_pdf

info = project_to_pdf(
    src_project='/path/to/project',
    to_dir='softcopyright',
    software_name='My Software',
    version=(1, 0, 0, 'final', 0),
)
print(info['pdf'], info['pdf_part'], info['source_lines'])
```

# astartool.file.file\_opt `[v0_4_2 变更]`

本模块所有路径参数（`file_path` / `path`）此前签注为 `str`，但实现均通过
`Path(...)` 转换，**实际同时接受 `pathlib.Path`**。v0_4_2 将类型注解统一为
`Union[str, Path]` 并在 docstring 中标注「str 或 pathlib.Path」，行为不变。

涉及函数：`read_large_file`、`write_large_file`、`read_file`、`write_file`、
`list_dir`、`search_content`、`list_archive`、`edit_file`。各函数说明详见
[v0_4](v0_4.md)。
