# astartool.project.\_log

函数式日志装饰器集合，用于在函数进入/退出时输出一条日志。进入与退出信息通过
`on_enter` / `on_exit` 输出，二者均可为以下三种形态之一：

- `None`：使用默认输出（`std_logging` 默认 `print`，`file_logging` 默认
  `logging.getLogger(__name__).log`）。
- 可调用 `callable(level, name, message)`：自行决定如何处置输出，其中 `message`
  为已格式化好的 `"enter name()"` / `"exit name()"` 字符串。
- 字符串模板：按 `str.format` 风格渲染后交给默认输出。模板中 `{}` 表示按位置引用
  （顺序为 `name`、`level`、`event`、`message`），`{name}` / `{level}` / `{event}` /
  `{message}` 表示按命名引用；此外模板还可直接引用**被装饰函数的形参名**
  （如 `{x}` / `{y}`），将被替换为对应实参值。未知命名字段渲染为空字符串，畸形模板
  （如括号不平衡）不会抛错（仅原样保留）。

可用变量说明：

- `level`：日志级别（字符串或整数，取决于调用方式）。
- `name`：被装饰函数名。
- `event`：当前阶段，`"enter"` 或 `"exit"`。
- `message`：完整的内置信息字符串，如 `"enter foo()"`。
- 被装饰函数的形参名：对应调用的实际参数值，例如 `foo(x, y)` 调用 `foo(1, y=2)`
  时 `{x}` 为 `1`、`{y}` 为 `2`。

## std\_logging `[v0_4_1 新增]`

```python
def std_logging(level=logging.INFO, on_enter=None, on_exit=None)
```

标准输出日志装饰器。被装饰函数执行前输出 "enter" 信息，执行后输出 "exit" 信息，
默认通过 `print("[level]: <enter|exit> name()")` 打印到标准输出。

**参数**:

- `level`: 日志级别，可为整数（如 `logging.INFO`）或字符串（如 `"INFO"`）。
- `on_enter`: 进入时的输出（可调用或字符串模板）；`None` 时使用默认 `print`。
- `on_exit`: 退出时的输出（可调用或字符串模板）；`None` 时使用默认 `print`。

**示例**:

```python
from astartool.project._log import std_logging

# 默认打印
@std_logging(level=logging.INFO)
def foo():
    return 42

# 字符串模板（命名/位置混合）
@std_logging(on_enter="-> {name} {event}", on_exit="<- {name} {event}")
def bar():
    ...

@std_logging(on_enter="call {} at {}")   # 位置: name, level
def baz():
    ...

# 自定义可调用 sink
def sink(lvl, name, msg):
    my_queue.put((lvl, name, msg))

@std_logging(on_enter=sink, on_exit=sink)
def qux():
    ...
```

## file\_logging `[v0_4_1 新增]`

```python
def file_logging(level=logging.INFO, on_enter=None, on_exit=None)
```

文件/标准 logging 日志装饰器。行为与 `std_logging` 一致，区别仅在于默认输出走
标准库 `logging.getLogger(__name__).log(level, message)`（使用模块级命名 logger，
由 `logging` 模块的 handler 决定最终落盘位置，如文件）。

**参数**:

- `level`: 日志级别，可为整数（如 `logging.DEBUG`）或字符串（如 `"DEBUG"`）；
  字符串会被映射为对应整数级别。
- `on_enter`: 进入时的输出（可调用或字符串模板）；`None` 时默认
  `logging.getLogger(__name__).log`。
- `on_exit`: 退出时的输出（可调用或字符串模板）；`None` 时默认
  `logging.getLogger(__name__).log`。

**示例**:

```python
from astartool.project._log import file_logging

@file_logging(level=logging.INFO, on_enter="enter {name}")
def foo():
    ...

@file_logging(level="DEBUG", on_enter=lambda lvl, name, msg: custom(msg))
def bar():
    ...
```
